Yoto Remote Test TEST PAGE

A throwaway page to find out whether remotely starting a card makes a Yoto player download it. It starts one card on one player for a few seconds, then stops it.

When you sign in, Yoto will warn that this app is unverified and will list a permission to remotely control your players. That is expected for this test. Check the address is login.yotoplay.com.

First-time set-up: paste the Client ID from the Yoto developer site for this test app.
